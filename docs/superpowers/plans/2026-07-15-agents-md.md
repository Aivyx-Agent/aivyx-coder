# AGENTS.md Project Instructions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user state persistent project-level (and user-global) guidance in an `AGENTS.md` file, auto-loaded into every turn's system prompt, refreshed live so edits apply without a restart.

**Architecture:** A new `AgentsFileSettings` config section plus a new `Settings::agents_file_path()` resolve *whether* and *where* to look; `Agent` gains a per-turn refresh (`refresh_agents_files`, mirroring the existing `refresh_repo_map` mechanism exactly) that reads both files, labels and concatenates whatever's present, and appends the result to the system prompt built by `assemble_messages`.

**Tech Stack:** Rust, tokio (plain `tokio::fs::read_to_string`, no new dependencies).

## Global Constraints

- `AgentsFileSettings::enabled` defaults to `true`; `budget_tokens` defaults to `1024`.
- Two fixed locations only: `<cwd>/AGENTS.md` (project) and `<config_dir>/AGENTS.md` (user-global, sibling to `config.toml`). No nested/subdirectory merging.
- No frontmatter, no structured metadata — plain prose, included as-is.
- Refreshed every turn (not read once at startup) — mirrors `refresh_repo_map`'s per-turn cadence exactly.
- Any read error (missing file, permission denied, not valid UTF-8, etc.) for either file is treated as "no content from this source" — never an `AgentError`, never fails the turn.
- Budget (`budget_tokens`) is applied **per file independently**, not as a combined pool.
- A file over its budget is still included **in full** — never truncated — but triggers exactly one `self.notify(...)` call per refresh where it's over.
- Merge order when both files are present: global content first, then a one-line precedence note, then project content. The note appears **only** when both are present.
- `run_turn_inner`'s refresh call site is the one at `crates/aivyx-core/src/agent.rs:921`, not the separate one inside `run_architect_turn` at line `717` (that one belongs to `run_architect_turn`'s own hand-rolled planning-context construction, out of scope here).

```rust
    /// Re-reads both `AGENTS.md` files off the async runtime. Best-effort:
    /// any read error for either file (missing, permission denied, not
    /// valid UTF-8) just means that source contributes nothing — this
    /// never fails the turn. Called once per turn (not once per LLM
    /// round-trip), mirroring `refresh_repo_map`'s cadence exactly.
    async fn refresh_agents_files(&mut self, cwd: &Path) {
        let Some(config) = &self.agents_file_config else {
            return;
        };
        let budget_chars = (config.budget_tokens as f64 * self.chars_per_token) as usize;
        let global_path = config.global_path.clone();
        let project_path = cwd.join("AGENTS.md");
        let budget_tokens = config.budget_tokens;

        let mut sections: Vec<String> = Vec::new();
        let mut over_budget_labels: Vec<&str> = Vec::new();

        if let Some(path) = &global_path
            && let Ok(content) = tokio::fs::read_to_string(path).await
        {
            let content = content.trim();
            if !content.is_empty() {
                if content.chars().count() > budget_chars {
                    over_budget_labels.push("user-level AGENTS.md");
                }
                sections.push(format!(
                    "User preferences ({}):\n{content}",
                    path.display()
                ));
            }
        }

        if let Ok(content) = tokio::fs::read_to_string(&project_path).await {
            let content = content.trim();
            if !content.is_empty() {
                if content.chars().count() > budget_chars {
                    over_budget_labels.push("project AGENTS.md");
                }
                sections.push(format!("Project instructions (AGENTS.md):\n{content}"));
            }
        }

        for label in &over_budget_labels {
            self.notify(format!(
                "{label} exceeds the configured [agents_file] budget_tokens ({budget_tokens} \
                 tokens) — trim it or raise the budget; the full content was still included."
            ));
        }

        self.agents_files_text = match sections.len() {
            0 => None,
            1 => Some(sections.remove(0)),
            _ => {
                let project = sections.remove(1);
                let global = sections.remove(0);
                Some(format!(
                    "{global}\n\n(Project instructions take precedence over user preferences \
                     if they conflict.)\n\n{project}"
                ))
            }
        };
    }
```
