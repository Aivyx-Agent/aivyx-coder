# aivyx-coder manual

aivyx-coder is a terminal coding agent for **local** models — Ollama,
Lemonade Server, llama.cpp, vLLM or Jan. The model reads, edits and runs
things in your project; every change waits for your approval, and a
layered permission and sandbox model keeps a mistaken or manipulated model
from quietly doing damage.

The manual has three parts: the guide for everyday use, the reference for
looking things up, and a developer part for contributors.
